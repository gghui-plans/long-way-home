# K-JAM dialogue script for ElevenLabs

One generation per bit, using the dialogue editor ("+ Add speaker"). That makes about 74 files instead of 167. Claude cuts each file into lines afterwards to sync the subtitles.

## How to build each bit

1. Make one speaker block per line, in order, choosing the speaker shown (RICK, DANA, CALLER-F or CALLER-M).
2. Paste only what comes after the speaker name: the [tag] and the words. Never paste the file name.
3. Generate, pick the better take, and download it as MP3 **named as the file name** (e.g. `traffic-01.mp3`). Drop it in your PC's Downloads folder.
4. If a tag sounds odd, delete it and regenerate. Tags are hints, not rules.

**Voices:** RICK is a dry, deadpan, world-weary man. DANA is a bright, upbeat, quick woman. CALLER-F (Brenda, Gloria) is a casual, friendly woman on the phone. CALLER-M (Kevin, Marco) is a laid-back, slightly sheepish man.

**Model:** Eleven v4, with Auto-tag off (the tags are already written in).
